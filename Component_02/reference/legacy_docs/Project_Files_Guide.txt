CATEGORY 1 — DATA PREPARATION
================================================================================

FILE: prepare_data.py                                              [CORE]
─────────────────────────────────────────────────────────────────────────
WHAT IT DOES:
  This is the FIRST script you run on a fresh setup.
  It reads the raw PTB-XL dataset and produces everything the training
  scripts need.

STEP BY STEP WHAT IT DOES:
  1. Reads ptbxl_database.csv (the raw 21,837-record dataset)
  2. Reads scp_statements.csv (the SCP code → superclass mapping table)
  3. Parses the scp_codes column (converts text dictionary to real dict)
  4. Filters codes with confidence < 100% (removes uncertain diagnoses)
  5. Maps surviving codes to 5 superclasses (NORM, MI, STTC, CD, HYP)
  6. Drops NORM if a pathological class is also present on same record
  7. Excludes records with no surviving superclass label
  8. Translates German cardiologist reports → English (GoogleTranslator)
  9. Splits data into train.csv / val.csv / test.csv using strat_fold
 10. Loads each 500Hz ECG signal, normalizes it, saves as .npy file
     → stored in data/signals_cache/<ecg_id>.npy
 11. Runs ClinicalBERT on each English report, saves [CLS] embedding
     → stored in data/text_cache/<ecg_id>.npy
 12. Computes per-lead signal mean/std → saves to data/norm_stats.json

RUN THIS WHEN:
  First time setup. You only run it once (it is slow due to BERT + translation).

OUTPUT FILES CREATED:
  data/train.csv
  data/val.csv
  data/test.csv
  data/norm_stats.json
  data/signals_cache/  (one .npy per ECG record)
  data/text_cache/     (one .npy per ECG record)

─────────────────────────────────────────────────────────────────────────

FILE: split_by_class.py                                            [EVAL]
─────────────────────────────────────────────────────────────────────────
WHAT IT DOES:
  A utility/analysis script. Reads the labeled CSV files and prints

  Useful for verifying the label distribution is correct before training.

RUN THIS WHEN:

  (NORM ~9500, MI ~5100, STTC ~5200, CD ~4700, HYP ~2600).

CATEGORY 2 — MODEL TRAINING SCRIPTS
================================================================================

FILE: train_ecg_only.py                                            [TRAINING]
─────────────────────────────────────────────────────────────────────────
WHAT IT DOES:
  Trains the ECG-ONLY ResNet 1D CNN classifier.
  This is the model used at inference time (in the web interface).
  It only uses the ECG signal — no demographics, no text.

WHY A SEPARATE SIGNAL-ONLY MODEL?
  The multi-modal model (train.py) is more accurate but slower.
  The signal-only ResNet is fast enough for real-time web inference.

ARCHITECTURE IT TRAINS:
  4-block 1D ResNet (ResidualBlock stacked 4 times)
  Channels: 12 → 64 → 128 → 192 → 256
  Kernels:  15 → 7 → 5 → 3
  Global Average Pool → Linear(256→128) → Linear(128→5) → Sigmoid

LOSS: Binary Cross-Entropy with per-class positive weights
OPTIMIZER: AdamW
SCHEDULER: CosineAnnealingWarmRestarts
EPOCHS: Up to 50 (early stopping patience=10)

OUTPUT:
  checkpoints_ecg_only/best_model.pt
  checkpoints_ecg_only/last_checkpoint.pt
  checkpoints_ecg_only/test_results.json

RUN THIS WHEN:
  After prepare_data.py. This is the primary model for deployment.

─────────────────────────────────────────────────────────────────────────

FILE: train.py                                                     [TRAINING]
─────────────────────────────────────────────────────────────────────────
WHAT IT DOES:
  Trains the FULL MULTI-MODAL FUSION CLASSIFIER.
  This is the research/comparison model — more powerful than signal-only.

THREE ENCODERS IT TRAINS TOGETHER:
  1. ECGEncoder    — 5-block 1D CNN on ECG signal → 256-dim vector
  2. DemographicEncoder — MLP on age/sex/height/weight → 64-dim vector
  3. TextProjector — Projects ClinicalBERT embedding → 128-dim vector

FUSION:
  Concatenate [256 + 64 + 128 = 448] → Linear layers → 5-class output

LOSS: Focal Loss (gamma=2.0) with per-class alpha weights
SAMPLER: WeightedRandomSampler (oversample minority classes like HYP)

OUTPUT:
  checkpoints/best_model.pt
  checkpoints/last_checkpoint.pt
  checkpoints/test_results.json

RESUME SUPPORT:
  If you stop training midway, just run again — it auto-resumes from
  last_checkpoint.pt.

RUN THIS WHEN:
  After prepare_data.py. Run for research comparison against signal-only.

─────────────────────────────────────────────────────────────────────────

FILE: train_report_gen.py                                          [TRAINING]
─────────────────────────────────────────────────────────────────────────
WHAT IT DOES:
  Trains the BioBART-based ECG REPORT GENERATOR.
  This model learns to generate English clinical ECG reports from
  the ECG signal directly (free-text generation).

HOW IT WORKS:
  ECG Signal → ECGBackbone (4-block CNN) → Linear projection (256→768)
  → Injected into BioBART encoder hidden states
  → BioBART decoder generates English text (teacher-forced during training)

BASE MODEL: GanjinZero/biobart-base (HuggingFace)
LOSS: Cross-entropy on token sequences
METRIC: ROUGE-L against English-translated cardiologist reports

OUTPUT:
  checkpoints_report_gen/best_model.pt
  checkpoints_report_gen/last_checkpoint.pt

NOTE:
  This model is used in TWO ways at inference time:
  - Tier 3: receives the Tier 2 template text and paraphrases it (SAFE)
  - Legacy: receives the raw ECG signal and generates freely (RESEARCH ONLY)

CATEGORY 3 — THE WEB INTERFACE
================================================================================

FILE: app.py                                                       [WEB — CORE]
─────────────────────────────────────────────────────────────────────────
WHAT IT DOES:
  The main Flask web server. Run this to start the web interface.
  Loads all models at startup and serves the analysis API.

WHAT RUNS INSIDE app.py:
  At startup:
    - Loads ECGResNet from checkpoints_ecg_only/best_model.pt
    - Loads ECGReportModel (BioBART) from checkpoints_report_gen/best_model.pt
    - Loads norm_stats.json for signal normalization
    - Loads test.csv and builds a class index for the patient browser

  API Routes served:
    GET  /              → Serve the web page (templates/index.html)
    POST /demo          → Pick a random test patient and analyze it
    GET  /patients/<c>  → Return list of test patients for class c
    POST /analyze/<id>  → Analyze a specific ECG by its ecg_id
    POST /predict       → Accept uploaded .dat + .hea file, analyze it

  For each analysis request it runs:
    1. Signal normalization
    2. ECGResNet → 5 probabilities
    3. Grad-CAM heatmap computation (last ResNet layer)
    4. Integrated Gradients lead importance (12 leads ranked)
    5. Tier 2 template report (via report_templates.py)
    6. Tier 3 BioBART smoothed report (paraphrase of template)
    7. Legacy BioBART free generation
    8. Matplotlib ECG plot with Grad-CAM overlay → base64 PNG
    9. Returns all results as JSON to the browser

HOW TO START:
  python app.py
  Then open: http://localhost:5000

─────────────────────────────────────────────────────────────────────────

FILE: report_templates.py                                          [WEB — CORE]
─────────────────────────────────────────────────────────────────────────
WHAT IT DOES:
  The TIER 2 TEMPLATE ENGINE. Pure Python — no neural network involved.

HOW IT WORKS:
  - Takes: sigmoid probabilities (5 floats) + decision thresholds (5 floats)
  - For each class: checks if prob >= threshold
  - If yes: determines severity tier (HIGH if prob >= threshold + 0.15,
            else MEDIUM)
  - Fills the appropriate pre-written clinical sentence for that class+tier
  - Joins sentences into a single report paragraph
  - Appends closing statement (normal vs abnormal variant)

WHY THIS EXISTS (the key design choice):
  This template cannot hallucinate because it ONLY produces sentences
  for classes that the CNN actually detected above threshold.
  The language is pre-written by a clinician, not generated by an LLM.

CLINICAL SENTENCE EXAMPLES:
  NORM high:  "The ECG is within normal limits. Sinus rhythm is present..."
  MI   high:  "ST-segment changes consistent with myocardial infarction. Urgent..."
  HYP  med:   "Borderline voltage findings present; ventricular hypertrophy..."

USED BY: app.py and predict.py

─────────────────────────────────────────────────────────────────────────

FILE: predict.py                                                   [WEB]
─────────────────────────────────────────────────────────────────────────
WHAT IT DOES:
  A COMMAND-LINE inference script (no Flask/browser needed).
  Run on a single ECG record from the test set or a custom file.
  Useful for quick terminal-level testing of the pipeline.

DIFFERENCE FROM app.py:
  app.py is the full web server serving a browser interface.
  predict.py is a standalone script for single-record CLI inference.

CATEGORY 4 — EVALUATION SCRIPTS
================================================================================

FILE: evaluate.py                                                  [EVAL]
─────────────────────────────────────────────────────────────────────────
WHAT IT DOES:
  Basic evaluation of the trained classifier on the test set.
  Loads best_model.pt, runs the full test set through it, and prints
  per-class AUROC and F1 scores with a summary table.

USE THIS WHEN:
  You want a quick pass/fail check on model performance after training.

─────────────────────────────────────────────────────────────────────────

FILE: evaluate_hybrid.py                                           [EVAL]
─────────────────────────────────────────────────────────────────────────
WHAT IT DOES:
  Full evaluation of the COMPLETE HYBRID PIPELINE including all three
  report generation tiers.

WHAT IT MEASURES:
  - Per-class AUROC and F1 (classifier performance)
  - ROUGE-L per tier (Tier 2 template / Tier 3 smoothed / Legacy free)
  - Hallucination rate per tier (clinical terms in output not in ground truth)
  - Exact match accuracy (all 5 labels correct)

USE THIS WHEN:
  You want the complete picture before deployment or for your thesis results.

─────────────────────────────────────────────────────────────────────────

FILE: check_accuracy.py                                            [EVAL]
─────────────────────────────────────────────────────────────────────────
WHAT IT DOES:
  Quick accuracy check — compares model predictions against ground truth
  for a subset of test records. Faster than evaluate_hybrid.py.
  Useful for sanity checking after a training run.

─────────────────────────────────────────────────────────────────────────

FILE: detailed_eval.py                                             [EVAL]
─────────────────────────────────────────────────────────────────────────
WHAT IT DOES:
  Runs a more detailed per-record evaluation. Shows individual prediction
  details (probability per class, prediction vs ground truth) for each
  record, rather than just aggregate statistics.

─────────────────────────────────────────────────────────────────────────

FILE: test_signal_only.py                                          [EVAL]
─────────────────────────────────────────────────────────────────────────
WHAT IT DOES:
  Tests the ECG-only ResNet model on a handful of records to verify
  the signal loading and normalization pipeline is working correctly.
  A quick smoke-test for the signal processing part.

─────────────────────────────────────────────────────────────────────────

FILE: verify_fix.py                                                [EVAL]
─────────────────────────────────────────────────────────────────────────
WHAT IT DOES:
  Verifies that a specific pipeline fix or patch is working correctly.
  Run after making changes to the model or preprocessing to confirm
  nothing broke. Also used to check the BioBART post-processing fixes
  (_fix_smoothed_output, _clean_text) are applied correctly.

CATEGORY 5 — AUDIT / ANALYSIS SCRIPTS
================================================================================

FILE: deep_audit_export.py                                         [EVAL]
─────────────────────────────────────────────────────────────────────────
WHAT IT DOES:
  Runs the FULL test set (1711 records) through the complete pipeline
  and exports a side-by-side comparison file for every record:
    - ECG ID
    - Ground-truth cardiologist report (English)
    - Tier 2 template report
    - Tier 3 smoothed report
    - Legacy free-text report
    - Predicted labels vs ground truth labels

OUTPUT FILE:
  audit_real_vs_generated.txt (1.5 MB — all 1711 records)

USE THIS WHEN:
  You want to manually review what the system generates vs what the
  cardiologist actually wrote. Essential for thesis validation chapter.

─────────────────────────────────────────────────────────────────────────

FILE: analyze_audit.py                                             [EVAL]
─────────────────────────────────────────────────────────────────────────
WHAT IT DOES:
  Reads audit_real_vs_generated.txt and computes statistical summaries:
    - ROUGE-L mean/median/std per tier
    - Hallucination rate per tier (clinical term frequency analysis)
    - Exact match accuracy across all 1711 records
    - Per-class precision, recall, F1 breakdown
    - Best and worst ROUGE-L examples per tier

OUTPUT FILE:
  audit_analysis_summary.txt

USE THIS WHEN:
  After running deep_audit_export.py, run this to get the summary table.

FOLDER: data/                                                      [DATA]
─────────────────────────────────────────────────────────────────────────
  Contains all processed dataset files.

  data/train.csv
    Rows: ~14,000 records (folds 1-8)
    Columns: ecg_id, patient_id, filename_hr, age, sex, height, weight,
             report_en, strat_fold, label_NORM, label_MI, label_STTC,
             label_CD, label_HYP, validated

  data/val.csv
    Rows: ~2,193 records (fold 9)
    Same columns as train.csv

  data/test.csv
    Rows: ~2,203 records (fold 10)
    Same columns as train.csv

  data/norm_stats.json
    Per-lead signal mean and standard deviation (computed on training set)
    Also contains demographic feature mean/std for normalization
    Used by: train.py, train_ecg_only.py, app.py, predict.py

  data/signals_cache/
    One .npy file per ECG record: <ecg_id>.npy
    Shape: (5000, 12) — 5000 time steps × 12 leads, float32
    Raw (un-normalized) signal values
    Normalization happens at load time in the Dataset class

  data/text_cache/
    One .npy file per ECG record: <ecg_id>.npy
    Shape: (768,) — ClinicalBERT [CLS] embedding, float32
    Pre-computed once by prepare_data.py, re-used every training epoch
